📌 Project Title - Leon Mut Repairs Website

📖 Project Description

This is a responsive website built for Leon Mut Repairs, a business that specializes in repairing and selling household appliances such as refrigerators, microwaves, washing machines, and power tools. The website is designed to help customers easily learn about the services offered, view products/services, and contact the business.

🎯 Project Purpose

The purpose of this project is to provide an online presence for the business, allow customers to understand available repair services, make contact information easily accessible, and showcase services in a clean and professional layout

🛠️ Technologies Used

HTML5 CSS3 VS Code / Live Server Netflify

💡 Features

*Responsive homepage layout *About Us section explaining the business *Services section showing repairs and sales *Contact information with phone/email *Clean navigation menu *Visual product/service cards

📌 Future Improvements

*Add online booking system *Add customer login system *Improve mobile responsiveness *Add database for service requests
